# 自動車整備記録システム

Google Apps Script (GAS) + Google Sheets で動作する自動車整備記録管理ツールです。

---

## 機能一覧

| 機能 | 説明 |
|------|------|
| 整備記録入力 | 自動車ごとに整備内容を入力するフォーム |
| 整備一覧 | 記録の一覧表示・編集・削除 |
| 燃費グラフ | Chart.js による燃費推移グラフ |
| 燃費自動計算 | 満タン法で燃費を自動算出 |
| OIL交換距離 | 前回オイル交換からの走行距離を自動表示 |
| 再計算 | 燃費・OIL交換距離を全件再計算 |
| CSVエクスポート | Google Drive へ BOM付きCSV出力 |
| CSVインポート | CSV貼り付けでデータ一括登録 |
| データ保存先指定 | エクスポート先フォルダを設定で指定 |
| 複数車両対応 | 車両ごとに専用シートを自動作成 |
| 写真URL登録 | Google Drive の共有URLを最大10枚登録 |
| スプレッドシート直接入力 | シートに直接入力後「再計算」で反映 |

---

## 整備種別

- 給油
- オイル交換（エレメント交換有無を選択可）
- タイヤ交換
- 車検
- 保険
- ワイパー交換
- 洗車
- その他整備

## セットアップ手順

### 1. Google スプレッドシートを作成

[Google スプレッドシート](https://sheets.google.com) で新しいスプレッドシートを作成します。

### 2. Apps Script エディタを開く

スプレッドシートのメニューから **「拡張機能」→「Apps Script」** を選択します。

### 3. ファイルを作成・コピー

Apps Script エディタで以下のファイルを作成し、それぞれの内容をコピーします。

#### サーバーサイド（.gs ファイル）

| ファイル名 | 説明 |
|-----------|------|
| `Code.gs` | メインコード・メニュー設定・定数定義 |
| `SheetManager.gs` | シート・設定管理 |
| `DataManager.gs` | データ CRUD 操作 |
| `Calculator.gs` | 燃費・OIL距離計算 |
| `ImportExport.gs` | CSV インポート/エクスポート |

#### クライアントサイド（.html ファイル）

| ファイル名 | 説明 |
|-----------|------|
| `Stylesheet.html` | 共通 CSS スタイル |
| `InputForm.html` | 整備記録入力フォーム |
| `MaintenanceList.html` | 整備一覧・燃費グラフ |
| `Settings.html` | 設定画面 |
| `ExportDialog.html` | CSV エクスポートダイアログ |
| `ImportDialog.html` | CSV インポートダイアログ |

#### プロジェクト設定

`appsscript.json` の内容を Apps Script プロジェクト設定（「プロジェクトの設定」→「appsscript.json を表示する」）に反映します。

### 4. 保存して実行

1. すべてのファイルを保存（Ctrl+S）
2. スプレッドシートに戻りページを更新
3. メニューバーに **「自動車整備記録」** が表示されます

### 5. 初回認証

初回実行時に Google アカウントの認証が求められます。
「詳細設定」→「安全でないページに移動（安全）」→「許可」の順にクリックします。

## 使い方

### 整備記録を入力する

「自動車整備記録」→「整備記録を入力」を選択します。

- **自動車名**：セレクトから選択（「追加」ボタンで新規登録可）
- **整備種別**：給油・オイル交換など選択すると関連フィールドが表示
- **給油時**：給油量・給油状態（満タン/非満タン）を入力
- **写真**：Google Drive の共有URLを貼り付け（最大10枚）

保存すると燃費・OIL交換距離が自動計算されます。

### 整備一覧を見る

「自動車整備記録」→「整備一覧を表示」を選択します。

- 種別・キーワードでフィルタリング可能
- 「編集」ボタンで記録を修正
- 「削除」ボタンで記録を削除
- 「燃費グラフ」タブで燃費推移をグラフ表示

### データ保存先を設定する

「自動車整備記録」→「設定」を選択します。

1. Google Drive でエクスポート先フォルダを開く
2. ブラウザのURLからフォルダIDをコピー
   - 例: `https://drive.google.com/drive/folders/`**`1ABCxyz123...`**
3. 設定画面の「Google Drive フォルダID」に貼り付けて保存

### スプレッドシートに直接入力する

各自動車のシートに直接データを入力できます。
入力後は「自動車整備記録」→「再計算」を実行すると燃費・OIL距離が更新されます。

---

## 燃費計算方法（満タン法）

1. 給油時に「給油状態：満タン」を選択
2. 前回の満タン給油から今回の満タン給油までの区間で計算
   - **距離** = 今回オドメーター − 前回満タン時オドメーター
   - **燃料** = 区間内の給油量合計（非満タンを含む）
   - **燃費** = 距離 ÷ 燃料

---

## データ列構成（各自動車シート）

| 列 | 項目 | 自動計算 |
|----|------|---------|
| A | 整備年月日 | - |
| B | 整備種別 | - |
| C | OILエレメント交換 | - |
| D | 給油量(L) | - |
| E | 料金(円) | - |
| F | メーター距離(km) | - |
| G | 給油状態 | - |
| H | 燃費(km/L) | ○ |
| I | 前回OIL交換からの距離(km) | ○ |
| J | メモ | - |
| K | 摘要 | - |
| L | 写真 | - |

---

## 注意事項

- 写真はGoogle DriveにアップロードしてURLを貼り付ける方式です
- 日付は入力時に `yyyy/MM/dd` 形式で保存されます
- CSVエクスポートはBOM付きUTF-8形式（Excelで直接開けます）
- スプレッドシートに直接入力した場合は「再計算」を実行してください
